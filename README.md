# כרטיס ביקור דיגיטלי — אמירה כהן

דף אינטרנט סטטי (HTML + CSS בלבד) המיועד להעלאה ל-GitHub Pages.

## מה יש בתיקייה
- `index.html` — התוכן והמבנה של העמוד
- `style.css` — העיצוב
- `assets/` — תמונות:
  - `ga-logo.jpg` — לוגו G&A גפני ואחדות
  - `amira-profile.jpg` — תמונת הפרופיל
  - `jerusalem-bg.jpg` — תמונת הרקע של ירושלים

**חשוב:** יש להעלות את **כל** התיקייה כולל תיקיית `assets` ותכולתה, ובאותו מבנה תיקיות בדיוק — אחרת התמונות לא ייטענו.

## מה עוד אפשר להוסיף בעתיד
- נכסים נבחרים אמיתיים (כרגע יש 3 תאים ריקים לדוגמה בסקציית "נכסים נבחרים")

## איך מעלים ל-GitHub Pages

1. צרו ריפו חדש ב-GitHub (למשל `amira-cohen-realestate`).
2. העלו את **כל** הקבצים והתיקיות מתוך התיקייה הזו לריפו (דרך "Add file" → "Upload files" באתר GitHub — ניתן לגרור את כל התיקייה בבת אחת, או דרך Git).
3. ודאו שבריפו נוצרה התיקייה `assets` עם שלוש התמונות בתוכה.
4. בריפו: `Settings` → `Pages`.
5. תחת "Build and deployment" בחרו Source: `Deploy from a branch`, Branch: `main`, תיקייה: `/ (root)`, ולחצו Save.
6. אחרי דקה-שתיים האתר יהיה זמין בכתובת:
   `https://<שם-המשתמש-שלך>.github.io/<שם-הריפו>/`

## איך עורכים תוכן בעתיד
כל הטקסט נמצא בקובץ `index.html`. חפשו את המילה `TODO` (עם Ctrl+F) כדי למצוא במהירות את המקומות שעדיין אפשר למלא (נכסים נבחרים).
